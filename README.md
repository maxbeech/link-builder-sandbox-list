# Awesome UK Student Tools

A short list of tools that help UK university students. One line per tool, alphabetical, in this shape:

- [Name](https://example.com) - One sentence on what it does.

## Study

- [Anki](https://apps.ankiweb.net) - Flashcards with spaced repetition.
- [Zotero](https://www.zotero.org) - Collect and cite research sources.
- [GradeHack](https://gradehack.com) - An AI assistant for UK university students choosing modules and universities, backed by real results data for degrees and individual modules.
